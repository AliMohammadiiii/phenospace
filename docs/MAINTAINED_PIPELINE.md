# Maintained demonstration and historical methods

The maintained `phenospace.graph_models` path is an adaptation, not a byte-identical extraction, of `experiments/real_data_pipeline/11_anndata/code/`. `anndata_to_pyg_v0.py` constructs participant/session graphs, `build_phenotype_graph_v0.py` combines phenotype relationships including empirical correlations, and `aanet_bottleneck_gnn_v0_1.py` implements an AANet-style batch convex hull. `train_aanet_bottleneck_gnn_v0_1.py` uses shuffled rows; its outputs retain their original protocol and must not be interpreted as the new inductive experiment. Versions `archetypal_bottleneck_gnn_v0.py` and `archetypal_bottleneck_gnn_v0_1.py`, their trainers, and `train_subgraph_masking_gnn_v0.py` are historical distinct variants; they are preserved as original sources rather than silently replaced. The included repository audit manifests map historical files to paths in the original archive; many listed files are not included in this public snapshot. No historical results were regenerated in this demonstration.

The maintained example fits means, scales and a positive weighted correlation graph to the named train rows alone, and saves their IDs and fit values. Held-out observed nodes are excluded from input and scored by MSE in standardized training units. The baseline predicts the train mean (zero in these units), on identical hidden nodes. The graph ablation drops between-node edges; the bottleneck ablation supplies each graph's own embedding directly to the decoder. These are engineering checks on one synthetic split, not statistical comparisons. Repeated-seed uncertainty, grouped/temporal cohorts, real participant data, and external validity remain future research.

The historical batch-hull computation depends on companion samples. The maintained model instead builds convex archetypes from saved, training-derived reference embeddings; references are refreshed each epoch and after training, then persisted. This is a different inference policy and experiment. Individual measurements are visible only where unmasked. All-constant or disconnected features may create a sparse or empty graph; GCN self-loops preserve node computation. Infinite values, duplicated IDs, incorrect axis order, invalid graph indices, and masks selecting missing measurements fail. No time or external phenotype-embedding features are used by this demonstration.

A new output directory prevents overwrite. Manifest schema 1 captures the synthetic input digest, exact split, fit parameters, versions, seed and results; source identity is available only when invoked from a Git checkout. For installed-wheel runs, accompany the artifact with the wheel digest and source revision externally. A dirty checkout requires preserving its diff to identify exact code. Training uses an ordinary deterministic CPU seed; portability across hardware and library versions is not guaranteed.

## Bounded variant characterization and source identity

The maintained entry point is `phenospace-demo`, implemented by `phenospace.graph_models.demo` using `pipeline.py`. Its AnnData instance flows through the same packaged `AnnDataPhenotypeGraphDataset` and `AANetStyleGraphBottleneckGNN` used in the tests. It is the only maintained training/inference path. The historical files below remain unchanged; the hashes identify source files under `experiments/real_data_pipeline/11_anndata/code/`, not experiment result files. The maintained reference-hull model makes a different choice from both the historical free-code and current-batch hull: learned queries mix **saved training reference embeddings**, held fixed at inference. It uses two features per node and weighted GCN only. It does not implement the original additional regularizers or time and semantic inputs. The maintained `fit_preprocessing`, adapter, masking loss and `grouped_split` form one tested utility path; importing them into the historical trainers or replacing those trainers with adapters would change their experiment contracts and defeat historical reproducibility. The original trainers continue to share their original dataset/masking helper. No legacy file is deleted or rewritten.
